# 诊断报告模板

构建诊断完成后按以下结构输出报告：

```markdown
## 构建诊断报告

**流水线**：{pipelineName}
**构建号**：#{buildNum}
**状态**：FAILED
**耗时**：{duration}
**触发链**：{父流水线} -> {当前流水线}

### 失败定位
- **Stage**：{stageName}
- **Task**：{taskName}
- **错误码**：{errorCode}

### 日志分析
{从日志中提取的关键错误信息}

### 根因分析
{错误原因分析}

- 若错误码是 `800006`：写明它只是分类，真正根因写步骤日志里的首次异常。
- 若含发布/提交：写清外部副作用（已提交 / 未提交 / 不确定），避免假绿假红。
- 不要只用最后一行日志下结论。

### 子流水线追踪
{递归诊断结果树}

### 构建历史
最近 N 次：成功率 X%，连续失败 Y 次
判定：{偶发失败/持续失败/环境问题}

### 修复建议
{具体修复方案}
```
