# 正式版与开发版并排安装

需要在同一台机器上同时留下正式版和开发版时，把它们规划成两套安装，而不是同一目录里换文件。
技术栈不限。安装器、界面框架、语言都可以不同。先定策略，再让手头的安装器满足这些约束。

## 一、先定两档，再选工具

仓库里放一份版本清单，至少分正式档和开发档。每档分开这些字段：

| 字段 | 作用 | 两档关系 |
|---|---|---|
| 显示名 | 窗口、安装包文件名、开始菜单、快捷方式 | 开发档标明 Dev，允许带空格 |
| 安装目录名 | 正常安装根目录下的文件夹 | 开发档 = 正式档目录名后直接加 `Dev`，不加空格或分隔符 |
| 应用标识 | 数据目录、卸载登记、登录态 | 必须不同，否则配置互相覆盖 |
| 图标 | 让人能分清眼前是哪一档 | 开发档用另一套 |
| 独占资源 | 端口、服务名、协议、开机启动项等不能共享的名字 | 必须不同，否则不能同时开 |

安装根用这个产品自己的正常 setup 路径。开发版是该路径上的兄弟目录，不是另一个盘符，也不是显示名本身。

显示名和安装目录名是两个字段。开发档显示名可以是「产品名 Dev」，目录名仍是「产品名Dev」。安装器若默认用显示名当文件夹，静默安装必须改写目标目录。

提交进仓库的产品配置只描述正式档。构建前对照清单检查它没有被开发档改写。

## 二、身份在构建期注入

用一个只接受这两档的选择（缺省正式档）决定本次构建。

1. 各端构建都读同一份清单，把选中档写进要发布的二进制和资源。
2. 运行时只读写进去的结果，不再看当时的选择。
3. 开发档用一次性覆盖注入显示名、标识、图标等差异。不要把覆盖写回正式档配置。
4. 构建结束，无论成功失败，都把被注入的产物恢复成正式档。工作区不能停在开发档上。
5. 选择一变，注入必须重做。增量缓存不能留下上一档的身份。

## 三、两档本地部署走同一条路

可以有两个入口，实现必须共用。差别只是选中的档和目标目录。

1. 选中对应档，完成注入。开发档使用一次性覆盖。
2. 打出真正的安装包。不要只编译出散文件。
3. 结束目标目录里已有的进程。文件被占用时，覆盖安装会失败。
4. 静默安装到钉死的目录：`安装根\<该档的安装目录名>`。
   正式档是覆盖安装，不跟随上一次向导选过的路径。
   开发档是装到正式档旁边，同样不跟随向导路径，也不跟随显示名。
5. 安装结果要和给人用的安装包一致：有卸载入口，有该档自己的快捷方式。

向安装器要的能力只有这些，不规定它的参数名字：

- 能静默，不弹出向导。
- 能指定目标目录，且这个目录盖过「按显示名生成文件夹」和「沿用上次安装位置」。
- 指定目录的写法以该安装器的规则为准。有的安装器要求路径放在最后、不能加引号；先用该安装器的文档核对，再用一次静默安装确认落点。

不要用拷贝二进制代替安装。拷贝没有卸载登记，没有快捷方式，目录布局也和真正安装不同，下一轮静默安装对不齐。

## 四、验收清单

- [ ] 正式版落在该产品的正常安装路径下
- [ ] 开发版目录是正式版目录名后面加 `Dev`，中间没有空格
- [ ] 显示名、安装目录名、应用标识是三个分开的字段
- [ ] 两档的标识、图标、独占资源都不同；数据目录跟标识走，不跟安装目录混用
- [ ] 仓库里的产品配置仍是正式档
- [ ] 开发档只在当次构建注入，结束后恢复正式档
- [ ] 两档都是「打安装包，再静默安装到钉死的目录」
- [ ] 正式版静默安装覆盖的是规范目录，不是上一次向导选过的别处
- [ ] 两套可以同时留在机器上，并各自卸载

## 五、失败模式

| 表象 | 常见原因 |
|---|---|
| 开发版目录带空格，或和显示名一模一样 | 静默安装没有改写目标目录，安装器使用了显示名 |
| 装回了上一次向导选的路径 | 静默参数没有盖过安装器记住的位置 |
| 静默参数被忽略 | 路径的位置或引号不符合该安装器的规则 |
| 覆盖安装失败，文件仍是旧的 | 目标目录里的进程没先停 |
| 开发版没有卸载入口和快捷方式 | 用拷贝产物代替了安装包 |
| 两档抢同一份配置或同一个端口、服务 | 标识或独占资源相同 |
| 仓库里留下开发档身份 | 构建结束后没有恢复正式档 |
| 正式包打成了开发档的名字或图标 | 开发档覆盖被写进了正式配置 |
| 换档后二进制仍是上一档 | 注入没有因档位变化而重做 |

## 六、适用范围

项目只要需要「本机同时保留正式版和开发版」，就按这一节规划，不必先选定框架。

已验证的一种落地是 Windows 当前用户安装：安装根为 `%LOCALAPPDATA%`，安装器要求把目标目录放在静默参数的最后且不加引号。换安装器或换安装根时，复用上面的字段和验收清单，只替换静默安装的具体写法。

按机器安装到需要提权的目录时，两档仍是兄弟目录，但静默安装要带上该安装器要求的权限。没有安装包的目标（例如只发一个可执行文件）不要硬套「静默安装」这一步，清单、目录名加 `Dev` 和构建期注入仍然适用。
